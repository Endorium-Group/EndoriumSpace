Sécurité & conformité

Conçu pour l'audit

Cryptographie standard (OpenSSL), MFA imposable, timeout d'inactivité, politique de mot de passe forte, audit infalsifiable et chiffrement de la base au repos.

Cryptographie éprouvée

SHA-256/HMAC, scrypt, AES-256-GCM et CSPRNG via OpenSSL. Aucune cryptographie maison.

Licence post-quantique

Signature hybride Ed25519 + ML-DSA-65, vérifiée 100 % hors-ligne — compatible air-gap.

Données protégées

Base chiffrée au repos (SQLCipher), secrets en coffre AES-GCM, backend non-root, TLS 1.2/1.3.

Conçu pour s'aligner sur les principaux référentiels

ANSSI ISO/IEC 27001 SOC 2 RGPD NIST 800-53 / 63B PCI DSS

Les contrôles techniques du produit sont conçus pour s'aligner sur ces référentiels et faciliter un audit. EndoriumFort n'est pas « certifié » : la conformité d'ensemble dépend aussi de contrôles organisationnels et d'un audit par un tiers accrédité, à la charge de l'organisation exploitante.

Souveraineté & air-gap

Vos accès ne quittent jamais votre périmètre

EndoriumFort fonctionne entièrement sur votre infrastructure, sans dépendance à un service cloud tiers et sans télémétrie imposée. Les licences Enterprise se vérifient hors-ligne, ce qui rend le produit utilisable dans des environnements totalement isolés.

La diffusion Enterprise peut se faire par tarball signé (docker load + vérification de signature), idéale pour les réseaux air-gap et les secteurs souverains.

# Air-gap : charger l'image depuis un tarball signé docker load < endoriumfort-ee.tar.gz cosign verify-blob --signature ... endoriumfort-ee.tar.gz # Licence vérifiée localement, sans aucun appel réseau [license] tier=enterprise state=valid offline=true
Déploiement

En production en quelques minutes

Choisissez votre cible. La Community est publique et gratuite.

# Lancer EndoriumFort Community docker run -d --name endoriumfort \ -p 443:443 -p 80:80 \ -v ef-data:/app/data \ ghcr.io/endorium-group/endoriumfort:latest # Le mot de passe admin initial s'affiche une fois dans les logs.
# Déploiement Kubernetes via Helm helm repo add endoriumfort https://charts.endoriumfort.example helm install endoriumfort endoriumfort/endoriumfort \ --namespace endoriumfort --create-namespace
# Environnement isolé : image + licence hors-ligne docker load < endoriumfort-ee-<version>.tar.gz cp licence.jws /app/data/license.jws # La licence se vérifie localement, aucun appel réseau requis.

FAQ

Questions fréquentes

Qu'est-ce que l'« open-core » ?
L'édition Community est libre et open-source : vous pouvez l'auditer, la builder et l'exécuter seule. L'édition Enterprise ajoute des modules premium, activés par une licence. Le code premium est physiquement absent du dépôt public.
Mes données partent-elles vers un cloud ?
Non. EndoriumFort est auto-hébergé : tout reste sur votre infrastructure. Aucune télémétrie n'est imposée, et les licences Enterprise se vérifient hors-ligne.
Est-ce utilisable en air-gap ?
Oui. L'image peut être chargée depuis un tarball signé et la licence se vérifie localement, sans aucun appel réseau — adapté aux environnements totalement isolés.
Comment fonctionne la licence Enterprise ?
C'est un fichier signé par une signature hybride post-quantique (Ed25519 + ML-DSA-65), vérifié 100 % hors-ligne. À l'expiration, le premium se désactive proprement sans casser le socle gratuit.
EndoriumFort est-il certifié ISO 27001 / SOC 2 / ANSSI ?
Les contrôles techniques sont conçus pour s'aligner sur ces référentiels et faciliter un audit. La certification elle-même relève d'un audit par un tiers accrédité et de contrôles organisationnels propres à votre organisation.
Puis-je migrer depuis un bastion existant ?
Oui, progressivement : déclarez vos ressources, importez vos identifiants dans le coffre, et basculez les accès au rythme de vos équipes. Voir la documentation du dépôt.
