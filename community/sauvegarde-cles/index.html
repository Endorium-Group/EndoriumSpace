Que faut-il sauvegarder exactement ?

exploitation sauvegarde

Je mets en place des sauvegardes. Les volumes suffisent-ils ?

Question fréquente · 2026-11-04
Réponse
Réponse de référence

Non. Il faut :

  1. le volume de données /app/data : base SQLite et journal d'audit ;
  2. la base PostgreSQL, si vous l'utilisez ;
  3. le volume du partage de fichiers, séparé de celui du bastion ;
  4. hors volume, vos clés : ENDORIUMFORT_VAULT_KEY, ENDORIUMFORT_AUDIT_HMAC_KEY, ENDORIUMFORT_FILESHARE_SECRET.

Sans la clé du coffre, les secrets restaurés sont illisibles ; sans la clé HMAC, le journal ne se vérifie plus. Gardez-les dans un gestionnaire de secrets, à part des archives.

Voir Sauvegarde & restauration.
