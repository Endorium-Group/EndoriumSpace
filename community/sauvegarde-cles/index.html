Que faut-il sauvegarder exactement ?

exploitation sauvegarde

Je mets en place des sauvegardes. Les volumes suffisent-ils ?

Question fréquente · 2026-11-04
Réponse
Réponse de référence

Non. Il faut quatre choses :

QuoiOùQuand
Volume de données/app/data (Docker), /var/lib/endoriumfort (Debian)toujours : base SQLite, journal d'audit
Base PostgreSQLvotre serveursi vous l'utilisez
Volume du partage de fichiers/data du conteneur endoriumfort-files, /var/lib/endoriumfort-files (Debian)si vous utilisez les lecteurs
Clés et configuration.env, docker-compose.override.yml ou /etc/endoriumfort/toujours

Le volume du partage de fichiers est séparé de celui du bastion : il s'oublie facilement.

Les clés, à part

ENDORIUMFORT_VAULT_KEY déchiffre les secrets du coffre, ENDORIUMFORT_AUDIT_HMAC_KEY permet de vérifier le journal, ENDORIUMFORT_FILESHARE_SECRET signe les tickets du partage de fichiers. Elles ne sont pas dans les volumes : sans la clé du coffre, les secrets restaurés sont illisibles ; sans la clé HMAC, le journal ne se vérifie plus. Gardez-les dans un gestionnaire de secrets, séparément des archives.

Sauvegarder (Docker)

Arrêtez le bastion le temps de la copie, pour une base et un journal cohérents :

docker stop endoriumfort endoriumfort-files
docker run --rm -v ef-data:/data -v "$PWD":/backup alpine \
  tar czf /backup/ef-data-$(date +%F).tar.gz -C /data .
docker run --rm -v ef-files:/data -v "$PWD":/backup alpine \
  tar czf /backup/ef-files-$(date +%F).tar.gz -C /data .
docker start endoriumfort-files endoriumfort

L'interruption dure quelques secondes. Sans arrêt, préférez un instantané (LVM, ZFS, snapshot cloud) : une copie à chaud d'une base SQLite en cours d'écriture peut être incohérente. Avec PostgreSQL, sauvegardez la base avec vos outils (pg_dump, sauvegarde continue) et le volume, pour le journal.

En paquet Debian, /etc/endoriumfort contient les clés : chiffrez l'archive qui l'inclut, ou stockez-la à part.

Tester

Planifiez la sauvegarde (cron, timer systemd) et restaurez-la au moins une fois. Après restauration, lancez Journal → Vérifier l'intégrité : c'est la preuve que la chaîne d'audit a survécu.
