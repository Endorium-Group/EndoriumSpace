Peut-on rendre la MFA obligatoire pour tout le monde ?

mfa securite

Je veux que personne ne puisse utiliser le bastion sans second facteur. Est-ce configurable ?

Question fréquente · 2026-11-04
Réponse
Réponse de référence

En CE, la règle est fixe :

CompteSecond facteur
Administrateursobligatoire, imposé côté serveur
Opérateurs et auditeursrecommandé, à l'initiative de chacun

Un nouvel administrateur n'accède qu'aux écrans de configuration initiale tant qu'il n'a pas enrôlé de second facteur, et aucun jeton ne permet de contourner cette étape. Un administrateur ne peut pas non plus retirer son dernier facteur.

Il n'existe pas de réglage pour l'imposer aux autres rôles.

Ce que vous pouvez faire

  • Repérer les comptes concernés : Administration → Utilisateurs, filtre Sans MFA uniquement, puis relancer leurs titulaires.
  • Suivre le bilan Administration → Sécurité, qui signale les administrateurs sans MFA.
  • Privilégier les passkeys : elles résistent à l'hameçonnage, un code TOTP non. Elles demandent le bastion en HTTPS sous son domaine définitif.
  • Enrôler deux facteurs par personne, par exemple une passkey et un TOTP de secours : la console ne propose pas de réinitialisation de MFA.
  • Limiter les droits : un auditeur en rôle auditeur, pas administrateur, et des affectations de ressources limitées au nécessaire.
  • Surveiller les connexions dans le journal : auth.login.success et auth.login.failure.

Enrôler un facteur

Chacun le fait depuis Mon compte → Sécurité :

  1. TOTP : scanner le QR code avec une application d'authentification, ou saisir le secret affiché, puis valider avec le code à 6 chiffres. L'heure du serveur et celle du téléphone doivent être justes.
  2. Passkey : Ajouter une passkey, puis suivre l'invite du navigateur (biométrie, code de l'appareil ou clé de sécurité). On peut en enregistrer plusieurs.

Perte d'un facteur

Avec deux facteurs, on se connecte avec l'autre et on remplace celui qui est perdu. Sans facteur de secours, un administrateur supprime puis recrée le compte sous le même identifiant ; l'historique reste dans le journal d'audit, et il faut réaffecter ses ressources.
