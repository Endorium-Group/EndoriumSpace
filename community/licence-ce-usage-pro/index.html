Puis-je utiliser la CE en production dans mon entreprise ?

licence editions

La CE est gratuite et son code est public. Puis-je la déployer pour administrer les serveurs de production de ma société ?

Question fréquente · 2026-11-04
Réponse
Réponse de référence

Non, pas sans licence. La CE est source-available, pas open source au sens de l'OSI :

  • gratuite pour l'usage personnel, pédagogique, de recherche, l'évaluation, les tests et l'usage interne hors production ;
  • tout usage commercial ou en production demande une licence Enterprise.

Évaluer la CE dans un environnement de test avant de décider est précisément l'usage prévu. Le fichier LICENSE du dépôt fait foi ; pour une offre, écrivez à contact@endorium.space.
