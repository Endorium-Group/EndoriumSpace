Quels identifiants utiliser au premier démarrage ?

installation premiers-pas

Je viens de lancer EndoriumFort CE et j'arrive sur l'écran de connexion. Quel compte utiliser ?

Question fréquente · 2026-11-04
Réponse
Réponse de référence

Sur une base neuve, le compte initial est :

IdentifiantMot de passe
adminAdmin123

À la première connexion, un écran de configuration de sécurité initiale bloque tout le reste jusqu'à ce que vous ayez :

  1. choisi un mot de passe privé ;
  2. enrôlé un second facteur (TOTP ou passkey).

Ce mot de passe est public. Faites cette étape juste après l'installation, avant d'exposer le bastion sur le réseau.

Si le volume de données a déjà servi, c'est le mot de passe choisi à ce moment qui s'applique. Voir Premier démarrage.
