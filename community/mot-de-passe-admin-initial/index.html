Quels identifiants utiliser au premier démarrage ?

installation premiers-pas

Je viens de lancer EndoriumFort CE et j'arrive sur l'écran de connexion. Quel compte utiliser ?

Question fréquente · 2026-11-04
Réponse
Réponse de référence

Sur une base neuve, EndoriumFort crée un seul compte administrateur :

IdentifiantMot de passe
adminAdmin123

Ouvrez https://votre-hote/ et connectez-vous avec ces identifiants.

La configuration de sécurité initiale

À la première connexion, un écran « Configuration de sécurité initiale » bloque tout le reste de la console jusqu'à ce que vous ayez :

  1. choisi un mot de passe privé : au moins 8 caractères, avec une majuscule, une minuscule et un chiffre. Visez beaucoup plus long : c'est le compte le plus sensible du bastion ;
  2. enrôlé un second facteur : un code TOTP (application d'authentification, QR code puis code à 6 chiffres) ou une passkey.

Ce blocage est appliqué côté serveur : ni l'API ni un jeton ne permettent de le contourner.

Ce mot de passe est public : il figure dans la documentation. Faites cette étape juste après l'installation, avant d'exposer le bastion sur le réseau. Tant qu'elle n'est pas terminée, n'importe qui peut la terminer à votre place.

« Identifiants invalides » avec admin / Admin123

Le compte initial n'existe que sur une base neuve. Si le volume de données (/app/data en Docker, /var/lib/endoriumfort en paquet Debian) a déjà servi, c'est le mot de passe choisi à ce moment-là qui s'applique.

Si l'écran affiche « Trop de tentatives », attendez : après 10 échecs en 5 minutes, le blocage dure de 30 secondes à 30 minutes, et même le bon mot de passe est refusé pendant ce temps.

Juste après

  • Créez un compte administrateur nominatif par personne (Administration → Utilisateurs → Nouvel utilisateur), et gardez admin comme compte de secours, avec un mot de passe long rangé dans un coffre.
  • Vérifiez que ENDORIUMFORT_VAULT_KEY est fournie avant d'enregistrer le premier mot de passe de cible : sans elle, il est stocké en clair.
  • Déclarez le domaine définitif (ENDORIUMFORT_WEBAUTHN_RP_ID, ENDORIUMFORT_WEBAUTHN_ORIGIN) pour que les passkeys fonctionnent.
