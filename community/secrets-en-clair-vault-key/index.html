Mes mots de passe de cibles sont-ils vraiment chiffrés ?

securite coffre configuration

J'ai enregistré des identifiants SSH dans le coffre. Comment savoir s'ils sont chiffrés en base ?

Question fréquente · 2026-11-04
Réponse
Réponse de référence

Ils ne le sont que si ENDORIUMFORT_VAULT_KEY est fournie et valide : exactement 64 caractères hexadécimaux.

openssl rand -hex 32

Sans clé, ou avec une clé mal formée, le bastion démarre quand même et enregistre les secrets en clair. Points d'attention :

  • le docker-compose.yml du dépôt ne transmet pas cette variable : ajoutez-la par un docker-compose.override.yml (voir Installation) ;
  • fournir une clé après coup ne chiffre pas les secrets existants : ressaisissez-les ;
  • rangez la clé hors de l'hôte : sans elle, les secrets ne se relisent plus.

Détails : Coffre-fort.
