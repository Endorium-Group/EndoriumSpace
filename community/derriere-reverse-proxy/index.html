Faire tourner le bastion derrière Caddy ou Traefik

reseau tls

J'ai déjà un reverse-proxy qui gère mes certificats. Que faut-il régler ?

Question fréquente · 2026-11-04
Réponse
Réponse de référence

C'est un déploiement courant : le proxy termine le TLS et relaie vers le bastion. Quatre points à respecter.

  1. WebSocket : les terminaux SSH et le navigateur isolé utilisent des WebSocket de longue durée. Le proxy doit les relayer, avec des délais d'inactivité d'au moins une heure.
  2. En-têtes : transmettez Host, X-Forwarded-For et X-Forwarded-Proto: https. Ce dernier active l'en-tête HSTS.
  3. Vraie adresse IP : déclarez l'adresse du proxy dans ENDORIUMFORT_TRUSTED_PROXIES (voir plus bas).
  4. Taille des requêtes : autorisez des corps assez gros pour les transferts de fichiers ; le partage de fichiers accepte 2 Go par défaut.

Proxies de confiance

ENDORIUMFORT_TRUSTED_PROXIES=10.0.0.5,172.18.0.0/16

Adresses ou plages CIDR, séparées par des virgules. Vide par défaut : personne n'est cru, et un client ne peut pas choisir l'adresse journalisée. Sans ce réglage, le bastion voit l'IP du proxy pour tout le monde : le journal est faux, et un seul utilisateur maladroit peut bloquer tous les autres par la limitation de débit.

Caddy

bastion.example.com {
    reverse_proxy https://endoriumfort:443 {
        transport http {
            tls_insecure_skip_verify
        }
    }
}

Le bastion reste en HTTPS derrière le proxy, avec son certificat auto-signé : d'où tls_insecure_skip_verify, sur ce seul saut interne. Caddy relaie les WebSocket sans réglage supplémentaire.

nginx

location / {
    proxy_pass https://127.0.0.1:8443;
    proxy_http_version 1.1;
    proxy_set_header Upgrade $http_upgrade;
    proxy_set_header Connection "upgrade";
    proxy_set_header Host $host;
    proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
    proxy_set_header X-Forwarded-Proto https;
    proxy_read_timeout 3600s;
    proxy_send_timeout 3600s;
    client_max_body_size 2g;
}

Traefik

Mêmes principes : un service vers https://endoriumfort:443 qui accepte le certificat interne, et des délais de point d'entrée compatibles avec des sessions d'une heure.

Ensuite

Déclarez le nom public pour les passkeys (ENDORIUMFORT_WEBAUTHN_RP_ID et ENDORIUMFORT_WEBAUTHN_ORIGIN), puis vérifiez le bilan Administration → Sécurité.
