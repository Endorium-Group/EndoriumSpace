Déposer une image ISO sur un hyperviseur à travers le navigateur isolé ?

rbi transfert-fichiers

J'administre un hyperviseur par le navigateur isolé du bastion. Je voudrais téléverser une ISO sur un datastore : c'est possible alors que le navigateur tourne sur le serveur ?

Question fréquente · 2026-11-04
Réponse
Réponse de référence

Oui. Deux façons :

  1. Glisser-déposer le fichier local sur la vue du navigateur isolé.
  2. Cliquer sur le bouton d'envoi de l'interface cible : le bastion intercepte le sélecteur de fichier et vous demande le fichier local, puis le remet à la page isolée.

Le fichier est écrit sur disque côté bastion, pas chargé en mémoire : une grosse ISO passe. ENDORIUMFORT_RBI_MAX_UPLOAD_MB permet de plafonner la taille.

Deux prérequis :

  • le moteur de rendu tiles, présent dans les images Docker publiées (le moteur cdp du paquet Debian ne transfère pas de fichiers) ;
  • en CE, les transferts ne sont pas filtrés : tout opérateur qui ouvre la ressource peut envoyer et récupérer des fichiers.
