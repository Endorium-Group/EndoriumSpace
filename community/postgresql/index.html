Utiliser PostgreSQL plutôt que SQLite ?

exploitation base-de-donnees

Nous avons un PostgreSQL géré et sauvegardé. Le bastion peut-il l'utiliser ?

Question fréquente · 2026-11-04
Réponse
Réponse de référence

Oui, sans changer d'image :

ENDORIUMFORT_DB_DSN=postgresql://endoriumfort:…@db:5432/endoriumfort?sslmode=require

Le bastion crée ses tables au premier démarrage. Pour migrer une installation SQLite existante, le dépôt fournit scripts/migrate-sqlite-to-postgres.py.

Deux précisions :

  • le journal d'audit reste un fichier sur le volume de données : gardez ce volume et sauvegardez-le ;
  • une seule instance du bastion à la fois, même avec PostgreSQL.

Voir Base de données.
